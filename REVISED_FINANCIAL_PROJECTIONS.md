# Nexus AI Studio — Revised Financial Projections (Multi-Platform)

## Updated Pricing Model

### Web SaaS
- **Free**: 50 requests/day, chat gear only → conversion funnel
- **Pro**: $30/month → all features, 5K requests/month
- **Studio**: $50/month → unlimited, teams, webhooks, API
- **Enterprise**: Custom $5K-$50K/month → SSO, audit, SLA

### Desktop Packaged App (Windows & Mac)
- **One-Time Purchase**: $49 (entry) / $79 (standard) / $129 (pro)
- **Subscription Option**: $20/month (Pro features), $40/month (Studio features)
- **Target**: Users wanting offline capabilities, no subscription commitment
- **Distribution**: Direct download, Windows Store, Mac App Store

### Mobile Apps (iOS & Android)
- **Free**: 50 requests/day, chat only
- **Pro**: $30/month (or $299/year) → all creation gears
- **Studio**: $50/month (or $499/year) → unlimited + team features
- **In-App Purchases**: Credits for high-usage ($9.99, $49.99 bundles)
- **Distribution**: Apple App Store, Google Play Store
