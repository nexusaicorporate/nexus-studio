# Pre-Deployment Checklist — Nexus AI Studio

Use this checklist before deploying to a fresh production server.

---

## Infrastructure & Server (Complete These First)

- [ ] **Server Provisioned**
  - [ ] Ubuntu 26.04 LTS (fresh installation)
  - [ ] 2GB+ RAM (4GB+ recommended)
  - [ ] 20GB+ disk space
  - [ ] Internet connectivity verified
  - [ ] SSH access confirmed
  - [ ] Root or sudo access available

- [ ] **Domain & DNS**
  - [ ] Domain name registered
  - [ ] DNS A record pointing to your server (if not using Cloudflare Tunnel)
  - [ ] OR Cloudflare Tunnel configured and ready
  - [ ] SSL certificate ready (or Cloudflare will handle it)

- [ ] **Network Configuration**
  - [ ] Port 22 (SSH) open for administration
  - [ ] Port 80 (HTTP) open for web traffic
  - [ ] Port 443 (HTTPS) open for web traffic
  - [ ] Port 5432 (PostgreSQL) closed to public (localhost only)
  - [ ] Firewall configured (UFW/iptables)

---

## Repository & Code

- [ ] **Repository Setup**
  - [ ] GitHub SSH key configured on server (or HTTPS auth)
  - [ ] Repository cloned to `/opt/nexus-studio` (or preferred location)
  - [ ] `.gitignore` includes `.env.local` (never commit secrets)
  - [ ] All required files present:
    - [ ] `package.json`
    - [ ] `next.config.mjs`
    - [ ] `prisma/schema.prisma`
    - [ ] `scripts/deploy_ubuntu_26.04_enhanced.sh`
    - [ ] `scripts/provision_users.mjs`
    - [ ] `modal/video_ltx.py` (for GPU backend)

- [ ] **Code Validation**
  - [ ] Run locally: `npm install && npm run build` (succeeds)
  - [ ] No TypeScript errors: `npx tsc --noEmit` (passes)
  - [ ] All environment variables documented in `.env.example`

## Secrets & Credentials (Prepare These)

- [ ] **NextAuth Secret**
  - [ ] Generate: `openssl rand -base64 32`
  - [ ] Store securely (password manager)
  - [ ] Will be set in `.env.local` during deployment

- [ ] **Admin User**
  - [ ] Email: `cscannell@nexusaigear.com` (or custom)
  - [ ] Strong password: (save securely)
  - [ ] Will be: `ADMIN_PASSWORD` env var

- [ ] **Test User**
  - [ ] Email: `test-studio@nexusaigear.com` (or custom)
  - [ ] Strong password: (save securely)
  - [ ] Will be: `TEST_PASSWORD` env var

### Optional: Stripe Integration (Test Mode)

- [ ] **Stripe Account**
  - [ ] Account created at stripe.com
  - [ ] Email verified
  - [ ] Phone verified

- [ ] **Stripe Test Keys** (from Stripe Dashboard → Developers → API Keys)
  - [ ] Secret key: `sk_test_...` (save securely)
  - [ ] Publishable key: `pk_test_...` (safe to expose)
  - [ ] Webhook secret: `whsec_...` (from Webhooks section)

### Optional: Modal GPU Backend

- [ ] **Modal Account**
  - [ ] Account created at modal.com
  - [ ] Email verified
  - [ ] Billing method added (required even for free tier)

- [ ] **Modal API Token** (from modal.com/account/tokens)
  - [ ] Token ID: `token-...` (save securely)
  - [ ] Token secret: `...` (save securely, shown once)

### Optional: Vision Model Keys

- [ ] **Google Gemini** (for vision analysis)

  - [ ] Vision API enabled in Google Cloud

## Deployment Parameters

Before running the deployment script, have these ready:

```bash
PUBLIC_URL=https://your-domain.example.com           # Required
ADMIN_PASSWORD='YourSecureAdminPassword123!'         # Required
TEST_PASSWORD='YourSecureTestPassword456!'           # Required
DB_NAME=nexus_studio                                 # Optional (default OK)
DB_USER=nexus_app                                    # Optional (default OK)
DB_PASS=<auto-generated if not provided>             # Optional
ADMIN_EMAIL=cscannell@nexusaigear.com               # Optional
TEST_EMAIL=test-studio@nexusaigear.com              # Optional
```

**Copy this template:**
```bash
sudo PUBLIC_URL=https://YOUR_DOMAIN \
     ADMIN_PASSWORD='YOUR_ADMIN_PASSWORD' \
     TEST_PASSWORD='YOUR_TEST_PASSWORD' \
     bash scripts/deploy_ubuntu_26.04_enhanced.sh
```

## Pre-Deployment Verification

- [ ] **Run Locally (Optional but Recommended)**
  ```bash
  npm install
  npm run build
  npm run start
  # Visit http://localhost:3000
  # Test login with admin credentials
  ```

- [ ] **Verify Environment Variables**
  - [ ] All required vars have values
  - [ ] No typos in domain name (PUBLIC_URL)
  - [ ] Passwords meet security requirements (12+ chars, mixed case, numbers)

- [ ] **Check Disk Space on Server**
  ```bash
  ssh root@your-server
  df -h
  # Ensure /opt has 20GB+ free space
  ```

- [ ] **Test SSH Access**
  ```bash
  ssh root@your-server
  # Confirm you can access and run commands
  exit
  ```

## Deployment Day

- [ ] **Before Script Execution**
  - [ ] No other deployments running on this server
  - [ ] Server is up-to-date: `sudo apt-get update && apt-get upgrade -y`
  - [ ] Have all passwords written down securely
  - [ ] Have terminal access to server
  - [ ] Block 30 minutes for deployment

- [ ] **Run Deployment Script**
  ```bash
  cd /opt/nexus-studio
  sudo PUBLIC_URL=https://your-domain \
       ADMIN_PASSWORD='...' \
       TEST_PASSWORD='...' \
       bash scripts/deploy_ubuntu_26.04_enhanced.sh
  ```

- [ ] **Monitor Deployment**
  - [ ] Watch output for errors (script stops on first error)
  - [ ] Note any warnings
  - [ ] Verify "DEPLOYMENT COMPLETE ✓" message at end
  - [ ] Check deployment log: `tail -n 100 deployment-*.log`

## Post-Deployment Verification

- [ ] **Application Running**
  ```bash
  pm2 status
  # Should show: nexus-web  online
  curl http://localhost:3000
  # Should return HTML (not error)
  ```

- [ ] **Database Created**
  ```bash
  psql -U nexus_app -d nexus_studio -h localhost
  # Should connect successfully
  \dt  # List tables
  \q   # Quit
  ```

- [ ] **Admin User Created**
  ```bash
  psql -U nexus_app -d nexus_studio -c "SELECT email, plan FROM \"User\";"
  # Should show admin and test users
  ```

- [ ] **Web Access**
  - [ ] Point your reverse proxy/tunnel to http://localhost:3000
  - [ ] Visit https://your-domain.example.com
  - [ ] Should see login page (no errors)
  - [ ] Login with admin email + password
  - [ ] Should see dashboard

- [ ] **NextAuth Callback**
  - [ ] Login redirect works
  - [ ] Cookies set correctly
  - [ ] No "callback URL" errors in browser console

## Emergency Rollback

If deployment fails partway:

```bash
# Check what failed
tail -n 100 deployment-*.log

# Stop the app
pm2 stop nexus-web

# Delete failed database (if necessary)
sudo -u postgres dropdb nexus_studio
sudo -u postgres dropuser nexus_app

# Start over with deployment script
```

## Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| `PostgreSQL: peer authentication failed` | Already configured by script; if manual: edit `/etc/postgresql/*/main/pg_hba.conf`, set `peer` → `md5` |
| `Port 3000 already in use` | `sudo lsof -i :3000` to find process; `kill -9 <pid>` or change port |
| `npm install hangs` | Check internet; try `npm install --prefer-offline` |
| `Build fails: out of memory` | Increase swap: `sudo fallocate -l 2G /swapfile` |
| `Prisma migration fails` | Check DATABASE_URL in `.env.local` is correct; verify Postgres is running |
| `NextAuth: invalid callback URL` | Ensure PUBLIC_URL matches exact domain users will visit |
| `Modal backend won't deploy` | Verify Modal account created, billing method added, `modal token new` run |
